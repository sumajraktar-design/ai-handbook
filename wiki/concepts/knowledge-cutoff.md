# 知识截止日期

> 模型训练数据的截止时间，之后发生的事情它不知道。

**分组**：使用模型 · **重要程度**：开发者必知

## 详细讲解

预训练数据收集到某个时间点就停止了，之后还有几个月的训练和测试才会发布。所以模型发布时，它的知识通常已经落后一段时间，而且这个差距会随着使用时间越来越大。

对于截止日期之后的事情，模型可能直接说不知道，也可能用旧知识给出过时的答案，甚至编造。比如问某个职位现在是谁担任，它可能给出截止日期时的人选。

解决办法是让模型使用搜索工具，或者通过 RAG 提供最新资料。

## 打个比方

一个在山里闭关了一年的人，他的知识停在进山那天，出山后需要看看新闻才能跟上。

## 开发者要注意

- 用模型写代码时，它可能推荐已经过时的库版本或 API 写法，要以官方文档为准。
- 涉及"最新""现在"的问题，给模型接上搜索。
