# 温度 / 采样

> 模型算出每个候选词的概率后，用来控制"怎么从中挑一个"的随机程度。

**分组**：大模型结构 · **重要程度**：很常见，要懂

> 原手册中有可交互的动画（组件名 `Temperature`），待迁移为 Vue 组件。

## 详细讲解

模型每一步的输出其实不是一个词，而是词表里所有 Token 的概率分布，比如"吃饭 45%、健身 20%、逛街 15%……"。接下来要从中选一个，这一步叫采样。

温度控制分布的"尖锐程度"。温度低（接近 0）时，高概率的词被进一步放大，几乎每次都选最可能的那个，输出稳定、保守。温度高时，分布变平，低概率的词也有机会被选中，输出更有变化，但也更容易离谱。

还有其他采样参数：Top-k（只从概率最高的 k 个里选）、Top-p（只从累计概率达到 p 的那些词里选）。

这也解释了为什么同一个问题问两次，回答会不一样。

## 打个比方

温度像点菜时的冒险程度：低温度永远点招牌菜，高温度偶尔会点一道从没吃过的怪菜。

## 开发者要注意

- 写代码、提取信息、回答事实问题：用低温度。写创意文案、头脑风暴：可以调高。
- 部分推理模型或 API 对温度有固定要求，以官方文档为准。
