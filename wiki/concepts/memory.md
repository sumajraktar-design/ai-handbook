# Memory 记忆

> 把重要信息存到对话之外，下次需要时再放进上下文，让 AI 能"记住"跨对话的内容。

**分组**：Agent 智能体 · **重要程度**：很常见，要懂

## 详细讲解

模型权重在使用中不会改变，上下文在对话结束后也就没了，所以模型本身不会记住你。产品里的"记忆"功能都是外部机制：把值得长期保存的信息（你的偏好、项目背景、做过的决定）写进文件或数据库，在之后的对话中按需读取，放进上下文。

常见的实现方式：一份简单的文本文件（每次对话开头读入）；按主题组织的多个文件，按需读取；用向量数据库存储，用检索的方式找到相关记忆（本质上就是对历史信息做 RAG）。

记忆系统的难点在于"记什么"和"何时用"：记太多会干扰判断、浪费上下文；记错了会一直带着错误；在无关的场景里突然提起旧信息，体验也不好。还要考虑隐私：哪些信息不应该被保存。

## 打个比方

模型像一个每天早上都会失忆的人，记忆功能就是他床头的笔记本：每天醒来先翻一翻，就知道之前发生过什么。

## 开发者要注意

- Agent 执行长任务时，让它把进度写进一个笔记文件，是最简单有效的"记忆"。
- 和压缩的区别：压缩解决"当前对话装不下"，记忆解决"跨对话记不住"。
