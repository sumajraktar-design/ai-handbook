# 数据隐私

> 发给模型 API 的内容会传到服务商那里，涉及敏感数据时要格外注意。

**分组**：安全与风险 · **重要程度**：很常见，要懂

## 详细讲解

使用云端 API 时，你的提示词、上传的文件、对话内容都会发送到服务商的服务器。需要关注的问题包括：数据是否会被用于训练模型、保存多久、存放在哪个国家或地区、谁能访问。不同服务商、不同套餐（个人版、企业版、API）的政策可能不同，要以官方条款为准。

常见做法：发送前对敏感信息脱敏（去掉姓名、身份证号、手机号等）；选择提供合适数据保护承诺的企业服务；对数据合规要求极高的场景，使用开源模型在自己的服务器上部署。

在应用层面，还要防止模型把一个用户的数据泄露给另一个用户，比如 RAG 检索时必须按用户权限过滤资料。

## 打个比方

把文件交给外包公司处理之前，你得先看清合同里写的保密条款。

## 开发者要注意

- 公司项目接入 AI 前，先确认公司的数据安全政策。
- RAG 和 Memory 系统都要做好按用户隔离。
